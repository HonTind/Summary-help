# 月度与对账工作台

独立核心新增在原包中，旧汇总模块、配置和接口保持不变。暂不改变正式版本号、旧打包产物或桌面启动入口。

## 核心接口

- `analysis.SheetRules(key_column="客户", amount_column="金额", sheet=None, header_row=1, key_fields=None, date_column=None)`：字段为精确表头名或从 1 开始的列序号。表头行从 1 开始，默认活动工作表（xls 为首表）；重名表头必须用列序号。两字段不能同列。省略 `key_fields` 时保持旧单键行为；给出 `key_fields`（1–8 项有序元组）时完全按该有序元组匹配，此时 `key_column` 不再参与，组合的第一项必须明确写在 `key_fields[0]`，不会自动把 `key_column` 当作第一项（`ordered_fields()` 也按同一规则报告：单键用 `key_column`，组合用 `key_fields`）。`date_column` 为可选的「按日期筛选」日期字段：默认 `None`（关闭，行为与旧版一致），给出精确表头名或列序号才启用，且不能与键列或金额列共用实际列；筛选开关只由 `date_column` 是否存在表示，不静默关闭。
- 组合键按顺序一一对应：`key_fields` 每项仍是精确表头名或列序号，同一实际列不能重复，键列不得与金额列重合；表头名与列序号指向同一列也会被拒绝。左右两侧字段数量必须相同，且在读取文件之前校验。
- `analysis.read_inputs(paths, rules, month=None, cancel=None, progress=None)`：仅读取显式选择的 xlsx/xlsm/xls。返回 ReadReport，含 records、issues、input_files、rules、files_loaded、scanned_rows、blank_rows、invalid_rows、excluded_rows 与 excluded。每条有效记录与异常保留文件、sheet、原 Excel 行号。异常行只计一次，文件级异常单列。启用日期筛选时须同时给出 `month`（YYYY-MM），并在每条数据行读取日期字段：日期合法但在本月之外的行作为「合法外月」计入 `excluded_rows` 并保留来源、原日期与规范日期（YYYY-MM-DD），不校验其键与金额，也不列为异常；日期缺失或非法才是异常（代码 `invalid_date`）。有效本月记录与各类异常行也保留原日期与规范日期（`Record`／`Issue` 的可选末尾字段，旧构造仍兼容）；界面与导出以独立日期列展示，不把日期塞进键列。
- `monthly.make_template(name, rules, output_prefix="月度汇总")`、`load_templates(path)`、`save_template(path, template, allow_update=False)`：版本 1 的规则模板，不保存输入文件名单或账单内容。日期规则只保存字段选择，不保存月份或业务日期值；未启用筛选时 `date_column` 不写入，旧 schema 1 模板继续按原字节结构读写。同名更新须调用方获得用户确认。损坏 JSON/未知版本拒绝保存，不重置；读取本身不改写磁盘，保存为原子替换。单一写入者使用，不承诺跨进程数据库锁。
- `monthly.run_monthly(paths, template, month, cancel=None, progress=None)`：月份为 YYYY-MM。模板启用日期筛选时，只汇总该自然月 `[月初, 下月月初)` 内的行，跨年与闰年按日历月处理，含时间也不漏当月最后一天；默认关闭时月份仅作标签、不按日期筛选。不定时运行，每月重新选择输入，返回分组 rows、精确 total、来源 report 和独立配置快照。
- `reconciliation.run_reconciliation(left_paths, right_paths, left_rules, right_rules, mode="customer", tolerance="0", cancel=None, progress=None)`：左右独立字段，可各自配置有序组合键；customer 按完整组合累计金额，document 只配唯一完整组合。任一侧完整组合重复时两侧该组合全部记录列为 ambiguous，不选第一条或自动合并；不同客户下同单号在 [客户,单号] 组合唯一时正常配对。
- `reconciliation.compare_reports(left, right, mode, tolerance)`：不做文件 I/O 的分类逻辑；consistent/different/left_only/right_only/ambiguous 互斥。difference 为左减右；独有、歧义金额缺项不用 0 冒充。complete 与 all_consistent 分开；读取异常、歧义或无有效输入不得称全部一致。
- `workbench_export.export_result(result, directory, prefix=None, cancel=None)`：调用者指定已有输出目录；创建唯一 xlsx、不覆盖文件或输入，输出结果、来源、异常和配置四表。来源明细与异常清单保留旧的前置列，并在其后追加独立日期列（原日期／规范日期）呈现日期溯源。金额列标为精确文本，不是可重算公式；需要 Excel 再计算时由用户另外转换处理。危险字符串按文字保存。超过 Excel 行数／单元格长度则报错，不截断。

## 数据边界

金额使用 Decimal 并扩展局部算术精度，不先四舍五入两位；容差默认 0、必须有限且非负。允许零与负数；不猜测货币符号、千分位或币种。仅接受纯数字／数字文本（最多 1000 位数字与指数绝对值 1000，避免异常数据耗尽资源）。键只去首尾空白，文本 001 与 1 不同；数值键按读取值转文字，建议单据号在源表存为文本。不做相似客户合并。

组合键以**结构化有序分量**匹配：顺序不同视为不同键；分量只是去首尾空白，保留大小写与内嵌符号，`["A|B","C"]` 与 `["A","B|C"]` 不相等，单键也不会与组合混配。任一键分量缺失、布尔、日期、Excel 错误值或无缓存公式都作为行级异常，保留来源与原始分量，不填空串参与匹配。界面与导出中组合键以可拆解的 JSON 数组文字显示，运行配置分别记录左右有序字段列表，不使用难以还原的普通拼接串作为匹配键。

不执行宏、不计算公式、不保存回输入；必需字段公式缺缓存或缓存为错误会报异常，请先在 Excel 重算保存。各格式的日期／错误单元格不能用作键或金额。进度仅文件级，取消为协作式；磁盘读取／保存期间不能保证立即中断。

启用日期筛选时，日期字段只接受真实 Excel 日期或 datetime、明确的文本格式 YYYY-MM-DD／YYYY/MM/DD／YYYYMMDD，或用工作簿 1900／1904 基准解码的数字序列。拒绝布尔、NaN／Infinity、非真实日期、`01/02/2026` 这类有歧义的格式、Excel 错误值和无缓存公式；datetime 按源值年月处理，不做时区猜测。日期数字序列按选中日期列在源工作簿中的原始数值校验（含日期样式与公式数字缓存），不依赖被读取库提前解码的日期：1900 基准中序列 1–59 是真实日期 1900-01-01 至 1900-02-28，序列 60 是虚构的 1900-02-29，序列 0 与负值不对应真实日期，都会明确报错而不静默纠正到 1900-02-28；1904 基准序列 0 是真实的 1904-01-01，时间分数取当日。外月行只校验日期、不校验键与金额，因此在来源表中以分类「日期排除」显示、金额标为「未校验」，键与金额为源表原值仅作对照，不会用 0 冒充；有效本月、日期已验但键或金额异常、坏日期各类行都保留原日期与规范日期，导出与界面以独立日期列呈现，缺失或非法日期仍作为异常，不能仅当外月忽略。

## 操作步骤

2026-10-13 源码入口改用统一离线窗口：侧栏「工作台」，顶部「常规汇总 / 月度汇总 / 账单对账」。月度与对账在当前窗口操作，不再从主入口另开工作台窗口；原 `WorkbenchWindow` 独立接口保留兼容。全局只允许一个后台业务任务，运行中可阅读教程和联系方式页，不能切换任务或修改执行规则。原正式 EXE/快捷方式尚未更新。

### 每月重复汇总

1. 选择「月度汇总」，重新选本月多个账单。
2. 设置键字段、金额字段；「工作表与表头设置」展开可选项。字段可填精确表头（如客户名称／货款），或 #1／#2 这样的列序号；数字表头名 2 与列序号 #2 不同。需要组合键时，把第一项填在「键字段①」，点击「添加组合字段」逐项填写后续字段，共 1–8 项，顺序即匹配顺序。显示层转换为原有有序字段规则，底层算法不变；独立兼容窗口仍可用原 JSON 输入。
3. 填模板名称，点击「保存规则」。同名更新会询问确认；下次打开可从下拉列表选名称并「读取模板」。模板文件为原 config 下新增 monthly_templates.json，不改旧 settings／field_config／history。
4. 可选「按日期筛选」：勾选并填写日期字段（精确表头名或 #列号，不能与键／金额同列）；勾选后填 YYYY-MM 只汇总该自然月，12 月与闰年二月按日历月处理。未勾选时月份仅作标签、不筛选，行为与旧版一致。预览结果、来源明细和异常；外月行在来源明细中以「日期排除」显示，并计入跳过行数，未校验其键与金额。来源明细与异常清单的独立日期列给出原日期与规范日期，数字序列按源工作簿基准解码后核对。
5. 点击「导出完整 Excel」，选择已有输出目录。结果不完整时须额外确认，异常仍随报告导出，不能当作无差错报告。

### 两份账单核对差异

1. 选择「账单对账」，分别选择左侧和右侧文件，独立填写两侧字段规则；同一侧可选多文件。两侧可分别配置组合键，但项数必须相同并按顺序一一对应（如左「客户,单据号」对右「买方,流水号」）。左侧设置较长时可滚动，结果、取消、导出按钮固定在右侧/底部。
2. 客户总额按完整组合键累加再比较；单据逐笔默认键名「单据号」，可按实际表头或改为组合键。完整组合重复只列歧义，不自动配对。默认容差 0，可明确调整。
3. 预览一致／金额差异／仅左／仅右／重复歧义，并核查来源与异常，再选择输出目录导出。

每页预览 100 行，可翻页；导出全量。改输入／规则会使旧结果失效，必须重做预览。运行中输入锁定且只能有一项任务；取消丢弃部分预览，关闭等待安全停止。磁盘操作期间取消可能延后；已完成保存的文件不会因晚到的取消请求而被删除。
